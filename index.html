NEOFORGE-ARCHITECT

Ollama · Gemma · prompt engineering

Własny Modelfile dla Ollamy, zamieniający model Gemma w wyspecjalizowanego asystenta do pisania modów NeoForge 1.21.1 w Javie. System prompt wymusza zasadę zera halucynacji API — nieznana klasa czy metoda zostaje oznaczona jako do zweryfikowania zamiast zmyślona — i zawiera pełną tabelę migracji z przestarzałego Forge API na NeoForge. Do tego osobny plik z przykładami few-shot, który da się wstrzyknąć bezpośrednio do Modelfile albo użyć jako regułę w Continue.dev.

owofier

Node.js · discord.js · webhooks

Bot na Discorda, który na życzenie przepisuje wiadomości użytkownika na „uwu-mowę” i wysyła je przez webhook w jego imieniu. Transformacja tekstu chroni linki, wzmianki oraz emotki (własne serwera i Unicode) przed zepsuciem, a lista aktywnych użytkowników trzymana jest lokalnie.
